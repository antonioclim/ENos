Architecture, identity and access

Keep the academic identifier (for example AP_1001_A) in your student records. The machine hostname is a separate DNS-compatible label: map that example to ap-1001-a by lowercasing and replacing underscores with hyphens. This is a technical mapping, not an authentication or grading rule. Usernames must also satisfy the installer: start with a lower-case letter, use a suitable unique local username and keep the full student identity separately.

Use a unique local password that you can retain securely. Never configure the shared historical example password stud on a network-accessible guest. Bridged mode exposes the guest to the surrounding network: use only an authorised lab network and scope SSH access to the intended host. A first SSH connection requires checking the guest fingerprint through the VM console.

Intel/AMD hosts: use an amd64 Ubuntu 24.04.x ISO. Apple Silicon: use the Arm64 VirtualBox host package and an arm64 guest ISO. Skip Intel VMX checks on Arm. Oracle platform requirements.

16. Common problems

You need to enable virtualisation in BIOS:

  1. Restart the computer
  2. Press Del, F2, F10 or F12 at boot
  3. Look for "Virtualization", "VT-x", "AMD-V" or "SVM"
  4. Change to "Enabled"
  5. Save and exit

Check Bridge settings in VirtualBox. Make sure you selected the correct interface (the one connected to internet).

In Ubuntu, try:

⬛ UBUNTU VM
sudo dhclient -v enp0s3
  1. Is the Ubuntu VM running?
  2. Is SSH running? sudo systemctl status ssh
  3. Is the IP correct? hostname -I
  4. Can you ping from host to VM?
