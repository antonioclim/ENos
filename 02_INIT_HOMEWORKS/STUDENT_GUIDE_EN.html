Use one Python environment

From the directory containing this candidate's recorder, create and activate a local environment. Install these dependencies explicitly; the recorder does not install system packages or change system Python.

python3 -m venv ~/.venvs/enos-recorder
source ~/.venvs/enos-recorder/bin/activate
python -m pip install rich questionary
python record_homework_tui_EN.py --offline

Keep that environment active for the run. System commands such as asciinema are separate prerequisites. Online mode additionally requires the confirmed port and the unresolved institutional contract; a practice group number does not disable networking.

Adopted local practice: Use --offline for practice. See the current recording contract. Institutional submission and official assessment remain deferred. Online material is conditional technical reference until its service contract and native acceptance are completed.

Initial Configuration (one time only)

💡
First use takes longer!
Install prerequisites explicitly, then use one Python virtual environment for installation and execution. The script checks dependencies without installing them.
1

Open the terminal

On Ubuntu/WSL, open a terminal.

🚨
WARNING! Use YOUR OWN terminal, installed and configured as your instructor has directed!

DO NOT connect to sop.ase.ro!

Use your own local practice environment. Submission eligibility is governed by the separately approved course policy, which is not selected by this guide.
2

Create the homework directory

# Create the HOMEWORKS directory in your home
mkdir -p ~/HOMEWORKS

# Verify it was created
ls -la ~/HOMEWORKS
ℹ️
~ represents your home directory (/home/{username}/)
3

Download the script

⬇️ Download Python TUI (Recommended) ⬇️ Download Bash (Alternative)
  1. Open WinSCP and connect to your Ubuntu/WSL system
  2. Navigate to /home/{username}/HOMEWORKS/
  3. Copy the downloaded file to this directory
# Enter the HOMEWORKS directory
cd ~/HOMEWORKS

# Download the Python TUI script directly from Google Drive
wget -O record_homework_tui_EN.py "https://drive.google.com/uc?export=download&id=1YLqNamLCdz6OzF6hlcPr1hr738DIaSYz"
💡
This method downloads the file directly into the HOMEWORKS folder, without intermediate steps!
# Files from Windows are at /mnt/c/Users/{WindowsName}/Downloads/
cp /mnt/c/Users/{WindowsName}/Downloads/record_homework_tui_EN.py ~/HOMEWORKS/
4

Make the script executable

cd ~/HOMEWORKS
chmod +x record_homework_tui_EN.py
5

Verify the structure

ls -la ~/HOMEWORKS/

You should see:

-rwxr-xr-x 1 {username} {username} 38000 Jan 21 10:00 record_homework_tui_EN.py

Recording

RECORDING IN PROGRESS

Tips for a good recording:

Common Problems

cd ~/HOMEWORKS
source ~/.venvs/enos-recorder/bin/activate
python record_homework_tui_EN.py --offline

Possible causes:

  • You are not connected to the internet
  • The server is temporarily unavailable
  • You are on a restricted network

Solution: The file is saved locally. Try again later.

# Check Python version
python3 --version

# Must be Python 3.8 or newer

Run the script again and enter the correct data. The recorder refuses to overwrite an existing recording. Preserve or move the earlier file before creating a new local recording; the institutional resubmission rule remains unresolved.
