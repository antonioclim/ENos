# SEM07 — Evidence review and public formative practice

> **Operating Systems** | ASE Bucharest — CSIE  
> Seminar 7: component evidence, practice drafts and descriptive reports

## Adopted local profile

The author has adopted descriptive component review and public formative use of the existing question banks. Institutional submission, authentication/key custody and official grading remain deferred. A local format result, a supplied policy file or a separate answer key does not establish those approvals.

Without an approved assessment policy, reviewed component evidence remains descriptive: final grades and eligibility decisions are unset and reports retain `PENDING_POLICY`. Missing evidence remains distinct from a reviewed zero. Explicitly supplied policy calculations are labelled `SUPPLIED_POLICY_UNVERIFIED` scenarios.

## Local review workflow

1. Preserve the submitted evidence and review missing, invalid or unsupported records explicitly.
2. Use the relevant local tool and inspect its report; an error or missing record does not invent a zero or an eligibility penalty.
3. Aggregate reviewed component values without `--policy` for a descriptive report. Supply a policy only for an explicitly labelled scenario until the official policy has been approved.
4. Use public question drafts for practice. A future controlled examination requires a separately approved bank, blueprint and distribution process.

The exact former README is retained in [policy history](POLICY_HISTORY.md). Its 25/50/25 formula, 80% thresholds, sanctions, oral-assessment and 85/15 proposals are not current active rules. No historical numerical rule is adopted by this local profile.
