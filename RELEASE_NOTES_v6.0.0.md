# ENos v6.0.0

ENos v6.0.0 consolidates the correction work and the author-approved D1–D7 teaching profile. It covers 14 core lectures, four supplementary lectures, seven seminars and 23 projects. The release source retains the v5.5.0 baseline and all recorded attribution, third-party terms and historical policy evidence.

## Release scope

- Corrected teaching models, examples, source-linked exports, local resource paths and generated teaching archives.
- Component licensing for eligible original material: MIT for software and code examples, CC BY 4.0 for teaching prose and figures. Retained SEM02 notices and third-party terms remain applicable.
- Explicit offline recording practice, descriptive assessment reports and public formative question banks. Final grades remain unset when no official policy has been adopted.
- A03 SHA-256 reference, coordinated representations and known-answer checks. The complete CLI and network application remain student implementation work.
- M14 synthetic local exercises with redacted previews, private output and bounded cleanup.
- Stable `6.0.0` repository, citation and Python package metadata, with a reproducible lecture archive and repository inventory.

## Verification and remaining acceptance

The D1–D7 implementation delivery records 164 distinct passed local cases: 152 unittest cases and 12 direct existing test functions. Its collector records seven passed checks, no failed checks and two checks not run. These figures refer to that identified implementation snapshot; release metadata preparation does not create additional test results. Exact source, patch and archive identity were checked in that delivery. [VERIFICATION.md](VERIFICATION.md) records the scopes and the earlier Phase 5/6 evidence separately.

The implementation environment lacked pytest and markdown-it-py, so that delivery did not establish a complete pytest run or a complete CommonMark link check. Its bounded ASan/UBSan retry disabled leak detection after an observed LeakSanitizer startup restriction; memory-leak detection remains unverified. Native Windows/PowerShell, browser and accessibility behaviour, supported VM/platform routes and institutional services retain their separately recorded acceptance status.

Institutional online submission, official grading rules and M14 use with real secrets remain deferred. These limits are part of the distributed teaching profile.
