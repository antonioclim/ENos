Bash Cheat Sheet

Seminar 1: Bash Shell | Operating Systems | ASE Bucharest

🧭 Navigation
  • pwd Print Working Directory - displays current directory
  • cd DIR Change Directory - changes directory
  • cd ~ Go to HOME directory
  • cd .. Go to parent directory
  • cd - Return to previous directory
  • ls -la Detailed listing with hidden files
Example
$ cd /var/log
$ ls -lh *.log
📁 Files & Directories
  • mkdir -p DIR Create directory(ies) recursively
  • touch FILE Create empty file or update timestamp
  • cp SRC DEST Copy files (-r for directories)
  • mv SRC DEST Move/Rename
  • rm FILE Delete file (-rf for directories)
  • cat FILE Display file contents
⚠️ Trap: rm -rf deletes permanently! There is no Recycle Bin.
📦 Variables
  • VAR="val" Set shell variable (no spaces around =!)
  • export VAR Makes variable accessible in subprocesses
  • echo $VAR Display variable value
  • unset VAR Delete the variable
  • env Display all environment variables
VariableMeaning
$HOMEHome directory
$USERCurrent user
$PATHExecutable search paths
$?Last command exit code
$$Current shell PID
💬 Quoting
Type Behaviour Example
'single' Everything literal '$VAR' → $VAR
"double" Expands variables "$VAR" → value
no quotes Expands + word split $VAR → problems with spaces
💡 Rule: Always use "$VAR" for files with spaces!
⚙️ Configuring ~/.bashrc
  • alias ll='ls -la' Define a shortcut
  • source ~/.bashrc Apply changes immediately
  • export PATH="..." Modify search paths
Useful function
mkcd() {
  mkdir -p "$1" && cd "$1"
}
💡 Backup: cp ~/.bashrc ~/.bashrc.backup before making changes!
✨ Globbing (Wildcards)
Pattern Matches Example
* Zero or more characters *.txt
? Exactly one character file?.txt
[abc] One character from set file[123].txt
[a-z] One character from the range file[a-c].txt
{a,b} Brace expansion {src,docs}
⚠️ * Does NOT include hidden files (those starting with . )
🗂️ FHS structure
DirectoryContent
/System root
/etcSystem configurations
/homeUser directories
/tmpTemporaryy files (cleanup follows system policy)
/varVariable data, logs
/usrUser programs
/binEssential executables
💡 /etc = Editable Text Configuration
⌨️ Terminal shortcuts
  • Tab Autocomplete command/path
  • Ctrl+C Interrupt current command
  • Ctrl+L Clear screen
  • Ctrl+R Search history
  • ↑ ↓ Navigate through history
  • Ctrl+A Jump to line beginning
  • Ctrl+E Jump to line end
