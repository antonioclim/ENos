Unexported Shell Variable

NUME="Ion"
echo $NUME           # Ion
bash -c 'echo $NUME'  # (empty!)

Environment Variable

export GLOBAL="valoare"
echo $GLOBAL          # valoare
bash -c 'echo $GLOBAL' # valoare
❌
Common mistake: VARSTA = 25 ← WRONG! Spaces are not allowed around =
Quoting

Single vs Double Quotes

┌─────────────────────────────────────────────────────────────────────────┐ │ 'single quotes' → NOTHING is interpreted (literal) │ │ "double quotes" → $variables and `commands` ARE interpreted │ │ no quotes → Everything is interpreted + word splitting │ └─────────────────────────────────────────────────────────────────────────┘ 
NUME="Student"

# Single quotes - everything literal
echo 'Hello $NUME'
# Output: Hello $NUME

# Double quotes - variables are expanded
echo "Hello $NUME"
# Output: Hello Student

# Unquoted lexical whitespace separates command words
echo Hello    $NUME
# Output: Hello Student (echo inserts one space between its arguments)
⚠️
Golden rule: Always use "$VARIABILA" with double quotes for files with spaces!
Configuration

The ~/.bashrc File

When is it executed?

NON-LOGIN SHELL (new terminal): ┌─────────────────┐ │ ~/.bashrc │ ← Executed! └─────────────────┘ INTERACTIVE LOGIN SHELL: ┌─────────────────┐ │ /etc/profile │ └────────┬────────┘ ▼ ┌─────────────────┐ │ ~/.bash_profile │ └────────┬────────┘ ▼ ┌─────────────────┐ │ ~/.bashrc │ ← only if the chosen profile explicitly sources it └─────────────────┘

After /etc/profile, Bash reads the first readable file among ~/.bash_profile, ~/.bash_login and ~/.profile. An interactive non-login Bash reads ~/.bashrc.

Typical content:

# Aliases
alias ll='ls -la'
alias cls='clear'
alias ..='cd ..'

# Environment variables
export EDITOR="nano"
export PATH="$HOME/bin:$PATH"

# Custom prompt
PS1='\u@\h:\w\$ '

# Useful functions
mkcd() { 
    mkdir -p "$1" && cd "$1"
}
💡
After modification, run source ~/.bashrc to apply changes without opening a new terminal.
Wildcards

File Globbing (Pattern Matching)

Pattern Description Example Matches
* Zero or more characters *.txt file.txt, note.txt, a.txt
? Exactly one character file?.txt file1.txt, fileA.txt (not file10.txt!)
[abc] One character from set file[123].txt file1.txt, file2.txt, file3.txt
[a-z] One character from range file[a-c].txt filea.txt, fileb.txt, filec.txt
{a,b,c} Brace expansion (lists) file{1,2,3}.txt file1.txt file2.txt file3.txt
⚠️
Trap: * does NOT include hidden files (those starting with . )! Use .* or ls -a.
