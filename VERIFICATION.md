## Reproducing bounded checks

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -e '.[dev]'
python -m pytest
python scripts/link_check.py --internal-only
python assets/tools/vendor_assets.py
python 00_SUPPLEMENTARY/validate.py
python scripts/inventory.py --update-readme
python scripts/build_formative_exports.py --check
python SEM07/final_test/test_bank/test_generator.py --validate
```

Dependency installation contacts the package registry. The subsequent link, vendor and supplementary integrity checks above are offline. They do not execute code examples from course documents. Project-specific tests and their prerequisites are described in the relevant seminar/project directories; privileged or service checks must not be inferred from a root unit-test pass.
