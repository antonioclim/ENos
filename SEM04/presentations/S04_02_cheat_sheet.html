Text Processing Cheat Sheet

Seminar 4 | grep • sed • awk • regex

🔤 Regex - Metacharacters
PatternDescription
.Any character (1)
^Start of line
$End of line
*0 or more
+1 or more (ERE)
?0 or 1 (ERE)
[abc]Character set
[^abc]Negated set
\Escape special char
⚠️ BRE vs ERE: grep default = BRE. Use grep -E for +, ?, |. GNU BRE also supports \+, \? and \| as extensions. Use LC_ALL=C when an ASCII range contract is required.
🔍 GREP - Options
OptionEffect
-iCase insensitive
-vInvert (does NOT match)
-nDisplay line number
-cCount LINES
-oOnly the match
-EExtended Regex
-rRecursive
-l / -LFiles with/without match
-A/-B/-C nContext lines
⚠️ -c counts LINES, not occurrences! Use grep -o | wc -l
🔍 GREP - Examples
# Search case-insensitive
grep -i 'error' log.txt

# Exclude lines whose first character is #; blank lines remain
grep -v '^#' config.txt

# Extract IPv4-shaped substrings (not validation; 999.999.999.999 matches)
grep -oE '([0-9]{1,3}\.){3}[0-9]{1,3}' log.txt

# Recursive in code
grep -rn 'TODO' --include='*.py' .
✂️ SED - Substitution
SyntaxEffect
s/old/new/First occurrence
s/old/new/gAll on line
s/old/new/iCase insensitive (GNU sed)
-iEdit in-place (no backup!)
-i.bakEdit with backup
/pattern/dDelete lines
&Entire match
\1, \2Captured groups
💡 Alternative delimiters: s|/usr|/opt| or s#old#new#
✂️ SED - Examples
# Replace all occurrences
sed 's/localhost/127.0.0.1/g' config.txt

# Delete comments
sed '/^#/d' config.txt

# Delete blank lines
sed '/^$/d' file.txt

# Edit in-place with backup
sed -i.bak 's/old/new/g' file.txt
⚠️ sed ... file > file truncates the input before sed reads it! Use -i.bak
📊 AWK - Variables
VariableContent
$0Entire line
$1, $2...Fields
$NFLast field
NFNumber of fields
NRLine number (global)
FNRLine number (per file)
FSInput Field Separator
OFSOutput Field Separator
⚠️ print $1 $2 = concatenated | print $1, $2 = with OFS (a space by default). Both forms are valid.
📊 AWK - Examples
# Print column 2
awk '{print $2}' file.txt

# Unquoted comma-delimited data only: column 3
awk -F',' '{print $3}' file.csv

# Quoted commas/newlines require a CSV parser, e.g. Python csv.
# Skip the first physical line in this restricted fixture
awk 'NR > 1 {print}' file.csv

# Sum column
awk '{sum += $1} END {print sum}' file

# Count per category
awk '{c[$1]++} END {for(k in c) print k, c[k]}'
📝 NANO - Commands
CommandAction
^OSave (Write Out)
^XExit
^WSearch (Where is)
^KCut line
^UPaste (Uncut)
^GHelp
^A / ^EStart / End of line
💡 ^ = CTRL | Common commands are shown in the footer; ^G opens help. Bindings depend on nano version/configuration.
🔗 Combined Pipelines
# Top 5 IPs from log
awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -5

# Remove full-line # comments and empty lines; preserve order
sed '/^#/d; /^$/d' config.txt

# Errors with frequency
grep -i error log.txt | awk '{print $NF}' | sort | uniq -c
