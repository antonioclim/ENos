What Does exec() Do?

Replaces:

Code segment, Data segment, Heap, Stack — the entire address space is replaced with the new program.

Preserves:

PID, PPID, File descriptors (if they do not have FD_CLOEXEC), Current working directory, Resource limits.

Important:

exec() does NOT create a new process — it replaces the content of the existing process. If successful, it does not return!
