What is a Zombie?

A zombie (defunct) process has exited but its parent has not yet collected its status with wait(). A kernel process record remains to preserve the exit status.

Zombies retain process-table/kernel metadata and exit status, but do not execute or retain the exited user address space.

What is an Orphan?

An orphan is a process whose parent has exited. In this init-only model it is adopted by init (PID 1).

The designated reaper collects adopted children after they exit; a brief zombie interval can still occur before collection.

Why Does It Matter?

Too many zombies can exhaust configured process limits. A limit of 32,000 is an illustrative assumption, not a universal Linux default. The system retains the exit-status record until the parent or designated reaper calls wait().

A programme that creates children must arrange for their exit status to be collected or explicitly use an appropriate automatic-reaping policy.
