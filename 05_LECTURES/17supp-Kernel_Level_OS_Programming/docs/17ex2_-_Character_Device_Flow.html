Lecture 17 • User Space ↔ Kernel Space Communication

Character Device = Special File

User-space applications communicate with kernel drivers through /dev/ entries. Device files are "gates" to driver functions: open(), read(), write(), close().

User ↔ Kernel Data Transfer

copy_to_user()

Kernel → User Space

Used in read() to send data from kernel buffer to application.

copy_to_user(user_buf, kernel_buf, count);
copy_from_user()

User Space → Kernel

Used in write() to receive data from application in kernel buffer.

copy_from_user(kernel_buf, user_buf, count);

IMPORTANT: You cannot directly access user space memory from kernel! Always use copy_to_user() / copy_from_user() and check their return values to handle invalid user ranges and partial transfers safely.
