How Does Journaling Work?

1. Write-Ahead Logging

Before overwriting home blocks, persist a complete redo record with the transaction’s after-images in the journal.

2. Persist the Commit

Persist the commit record only after the complete redo payload is durable. The transaction is now eligible for replay.

3. Checkpoint and Reclaim

Checkpoint committed data to home locations, then reclaim the log. Recover committed transactions; discard incomplete uncommitted records.
