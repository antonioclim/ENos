Educational purpose only - understanding security concepts

The historical gets() demonstration is intentionally unsafe and was removed from ISO C11. Reserve space for the NUL byte, validate lengths and check return values. gets · strncpy semantics · scanf field widths.

Conceptual byte layout

The copied C string includes its terminating zero byte. This display encodes text as UTF-8 and uses a declared little-endian 32-bit teaching layout. Seven ASCII characters plus NUL fit in an eight-byte buffer; eight characters do not. Every change reconstructs the original saved values before copying. The vulnerable demonstration remains intentional and is not executed as native unsafe code.

Vulnerable Code (C)

#include <string.h>
void vulnerable_func() {
char buffer[8];
int secret = 0;
gets(buffer); // UNSAFE!
if (secret != 0) {
grant_access();
}
}
Problem:

gets() does not check the destination buffer length and can write beyond it.

Modern Protections

Stack Canary ON

Special value between buffer and return address. If modified → controlled crash.

ASLR ON

Address Space Layout Randomisation changes selected mappings when enabled; coverage and entropy depend on platform and configuration.

DEP/NX Bit ON

Data Execution Prevention. The stack mapping is non-executable when this protection is enabled.

Bounds and Termination USE

Use a bounded input operation such as fgets() with the actual destination size and check its result. strncpy() does not guarantee NUL termination when the source reaches the bound; handle termination and truncation explicitly. Never use gets().

Attack Categories

1. Variable Overwrite

Overwrites adjacent variables, such as flags or counters

2. Return Address Hijack

Changes saved control-flow data in the conceptual layout

3. Code Injection

Injects and executes shellcode (blocked by DEP)

4. ROP (Return Oriented)

Chains existing "gadgets" to bypass DEP

Safer Coding Practices

DO NOT use:
gets() - no bounds checking
strcpy() - may overflow
sprintf() - format string + overflow
scanf("%s") - without limit
Use:
fgets(buf, size, stdin)
strncpy(dst, src, n) /* may omit NUL; not a drop-in safe string copy */
snprintf(buf, size, fmt, ...)
scanf("%7s", buf) - for an 8-byte buffer; check the conversion result
