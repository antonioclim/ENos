Producer-Consumer Problem

Description:

  • Producer: generates data and puts it in buffer
  • Consumer: removes data from buffer and processes it
  • Buffer: fixed size N (bounded buffer)

The 3 Semaphores:

empty = N: free slots available
full = 0: occupied slots available
mutex = 1: exclusive access to buffer
