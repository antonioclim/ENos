Blocked processes wait in FIFO order. When signal() is called, the first process is unblocked.

Operations Pseudocode

wait(S) / P(S) / down(S):
S = S - 1;
if (S < 0) {
block(process);
}
signal(S) / V(S) / up(S):
S = S + 1;
if (S <= 0) {
wakeup(first_blocked);
}

Key Concepts

Semaphore — Definition:

  • Integer variable accessed only through atomic operations
  • wait(): decrements and blocks if < 0
  • signal(): increments and unblocks a process
  • Operations are atomic (indivisible)

Value Interpretation:

S > 0: S resources available
S = 0: No permits available and no queued waiters
S < 0: |S| processes are blocked in queue
