The 3 Essential Requirements

Mutual Exclusion

Mutual Exclusion

If process Pi executes in its critical section, no other process may enter the same protected critical section.

Status: Select an algorithm

Progress

Progress

If no process is in the critical section and some request entry, selection must not be postponed indefinitely.

Status: Select an algorithm

Bounded Waiting

Bounded Waiting

There is an upper bound on how often other processes enter after a process requests entry.
