Key Concepts

Race Condition

A result depends on the relative ordering of thread operations. Different permitted interleavings can produce different outcomes.

Critical Section

A code region that accesses shared state and requires the appropriate synchronisation to preserve its invariant.

Mutual Exclusion

Permit only one thread in the protected critical section at a time, using an appropriate mutex, binary semaphore or other proven protocol.
