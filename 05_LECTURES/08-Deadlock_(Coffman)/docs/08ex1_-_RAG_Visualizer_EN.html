RAG Rules

  • Request Edge (P→R): Process P requests resource R
  • Assignment Edge (R→P): Resource R is allocated to process P
  • Cycle in the graph = Potential Deadlock
  • Resources single-instance: Cycle ⟹ Deadlock
  • Resources multi-instance: Cycle ⟹ possible Deadlock

Understanding Deadlock through a RAG

Necessary Conditions (Coffman)

  1. Mutual Exclusion: A resource instance is held exclusively by one process
  2. Hold & Wait: A process holds resources while requesting others
  3. No Preemption: Resources cannot be forcibly taken away
  4. Circular Wait: A circular chain of processes waiting for resources

Detection Algorithm (DFS)

  1. Start DFS from each unvisited node
  2. Mark the node as currently being visited
  3. Visit neighbours recursively
  4. A back edge to a currently visiting node identifies a cycle
  5. Mark the node as fully visited
