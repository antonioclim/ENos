Separate device utilisation

Each percentage uses that device’s own capacity over a model interval; CPU, GPU and NPU percentages are not parts of one 100% total. The bars therefore remain separate. Task assignments, power and utilisation values are fixed instructional inputs without established measurement provenance. The NPU item represents neural inference; tokenisation/preprocessing remains a CPU task unless a specific supported runtime says otherwise. An integrated accelerator need not use PCIe.

What is Heterogeneous Computing?

Systems that combine different processors (CPU, GPU, NPU/TPU) to execute tasks on a suitable processing unit. Suitability depends on workload, transfer costs, precision, software support and the hardware configuration.

CPU: Complex logic, branching
GPU: Massive parallelism, graphics
NPU: AI/ML, matrix ops
