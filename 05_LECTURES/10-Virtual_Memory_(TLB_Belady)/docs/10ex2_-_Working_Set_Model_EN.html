Definitie

WS(t, Δ) = {pages referenced in [t-Δ+1, t]}

The working set at reference t, with window Δ, contains the distinct pages accessed in the last Δ references.

Key Concepts

Locality Principle: Many programmes access a relatively small page set over a short interval; locality varies with workload.
WSS (Working Set Size): |WS(t, Δ)| - the number of pages in the working set.
Choosing Δ: Too small can miss a locality phase; too large can retain pages no longer in current use.
