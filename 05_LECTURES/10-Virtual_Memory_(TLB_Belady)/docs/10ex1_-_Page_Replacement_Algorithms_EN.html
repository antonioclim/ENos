Comparison

FIFO

Simple, but can exhibit Belady’s anomaly: more frames can produce more faults.

LRU

Uses past recency rather than future knowledge. Exact LRU is a stack algorithm; maintaining exact recency has a cost.

Optimal

The offline minimum for a known trace. Requires future references, so it is a comparison oracle rather than an online policy.

Clock

Uses reference bits and a circular hand to approximate recency; it is not exact LRU.

Belady’s Anomaly Detected

With FIFO, increasing the number of frames can increase page faults. This anomaly does not occur with stack algorithms such as exact LRU and OPT.
