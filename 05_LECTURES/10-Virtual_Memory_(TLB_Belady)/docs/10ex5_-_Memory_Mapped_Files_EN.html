Memory-Mapped Files

Access mapped file bytes through memory loads/stores rather than explicit read()/write() calls for each access.

MAP_SHARED: Changes can be shared through the mapping and written back to the file; synchronisation and persistence require explicit handling
MAP_PRIVATE: Copy-on-write: modifications are private to the mapping and do not update the file

Avantaje

Zero-copy: Can avoid an explicit copy between a kernel buffer and a separate user buffer; this is not a universal zero-copy guarantee
Lazy loading: Pages are faulted in when accessed if not already resident
Sharing: The same file can be mapped by multiple processes
Simplicity: Array-like access instead of explicit seek/read sequences
