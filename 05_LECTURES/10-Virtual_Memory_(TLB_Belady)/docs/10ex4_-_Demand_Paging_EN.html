Demand Paging

Pages are brought into memory on demand when accessed and not already resident.

Potential benefits: Less eager loading and memory use
Trade-off: A non-resident first access incurs a page fault

Page Fault Cost

Memory access: ~100 ns
Page fault (SSD): ~100 µs
Page fault (HDD): ~10 ms
Ratio of these illustrative inputs: 1 : 1000 : 100000
