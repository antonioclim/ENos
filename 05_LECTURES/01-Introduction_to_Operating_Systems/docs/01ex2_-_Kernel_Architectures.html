Advantages

  • High performance

    Direct communication between components, without message passing overhead

  • Efficient system calls

    This schematic syscall has one entry and one return; blocking and interrupts can add transitions

Disadvantages

  • Vulnerable to crashes

    A bug in any driver can crash the entire system

  • High complexity

    The kernel becomes huge and hard to maintain (Linux: ~30 million lines of code (illustrative, unverified count))

Advantages

  • Very stable

    An isolated filesystem-server failure need not corrupt the kernel, but dependent services can still be disrupted

  • Enhanced security

    Minimal attack surface in kernel, isolated components

  • Easy to extend

    New services can be added without modifying the kernel

Disadvantages

  • Lower performance

    Multiple IPC transitions for simple operations

  • Message passing overhead

    Data copying between different address spaces

Advantages

  • Performance/stability balance

    Combines architectural choices; actual costs and isolation depend on service placement

  • Modularity

    Drivers and services can be loaded/unloaded dynamically

Disadvantages

  • Architectural complexity

    The combination of paradigms increases complexity

  • Bugs in kernel are still dangerous

    A faulty kernel component can crash the system

Real Examples

Windows NT/10/11 macOS (XNU) BeOS/Haiku
