Hard vs Symbolic Links

Interactive demonstration of differences between link types

HARD LINKS

/home/user/
file.txt inode 100
/home/backup/
backup.txt inode 100
INODE 100
links: 2
data
How it works:

Both names point directly to same inode. They are separate entries in different directories but refer to the same data.

SYMBOLIC LINKS

/home/user/
file.txt inode 100
/home/
shortcut inode 200
INODE 100
links: 1
INODE 200
links: 1
"/home/user/file.txt"
How it works:

The symlink has its own inode which stores only a path string. On access, the system follows the path.

Linux Commands

Hard Link

$ ln file.txt backup.txt
Create hard link backup.txt → file.txt
$ ls -li file.txt backup.txt
Verify: same inode number
$ stat file.txt | grep Links
Verify link count

Symbolic Link

$ ln -s /home/user/file.txt shortcut
Create symlink shortcut → file.txt
$ ls -l shortcut
Shows: shortcut -> /home/user/file.txt
$ readlink shortcut
Displays the symlink target
