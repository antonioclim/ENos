TCP vs UDP Comparison

Lecture 15 • Transport Protocols

Transport guarantees and workload provenance

TCP offers an ordered reliable byte stream, with possible connection failure; it does not guarantee that every packet reaches its destination. UDP has an 8-byte header and applications can add ordering/reliability. QUIC runs over UDP and HTTP/3 uses QUIC, so reliable file/content delivery is not inherently TCP-only. Named-platform examples on this page are illustrative and are not verified current deployment claims. The charts evaluate fixed constants and animation settings, not network benchmarks. Interactive Scenarios - Why Does It Matter?

Video Streaming

Netflix, YouTube

UDP: "Lost media update? The application may continue with the next one."
TCP: "Missing stream bytes? Retransmission can delay later delivery."
✓ UDP Preferred

File Transfer

FTP, Downloads

TCP: "Each byte matters: retransmit until acknowledged or the connection fails"
UDP: "A transfer must detect and recover missing/corrupt application data or fail."
✓ Reliable application delivery required

Online Gaming

FPS, MMO

UDP: "A position update from 100 ms ago may no longer be useful"
TCP: "Retransmission can increase delay."
✓ UDP Preferred
