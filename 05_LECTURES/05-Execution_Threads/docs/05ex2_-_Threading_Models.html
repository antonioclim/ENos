Course 05 — Threading Models: 1:1, N:1, M:N

CPUs: 2

Model assumptions

Each CPU runs at most one kernel thread. Ready work waits for a CPU. In this fixed-mapping example N:1 uses one kernel thread and M:N maps U1/U2 to K1, U3/U4 to K2, without migration. A genuinely blocking syscall stalls that kernel thread while any of its selected requests remains pending. User-level nonblocking I/O or runtime replacement/migration can behave differently. Each button toggles only its own pending request.
