Formulae

page_num = floor(addr / page_size)
offset = addr % page_size
physical = frame * page_size + offset
offset_bits = log₂(page_size)

Concepte

Page: A fixed-size block in logical memory
Frame: A corresponding fixed-size block in physical memory
TLB: A cache of address translations; lookup cost is architecture-dependent
Page Fault: The page is not resident and must be loaded
