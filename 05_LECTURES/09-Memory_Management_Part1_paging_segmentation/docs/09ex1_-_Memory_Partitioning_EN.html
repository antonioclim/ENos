Placement Algorithms

First Fit

Use the first sufficiently large hole. Search may be short, but repeated placement can fragment the beginning of memory.

Best Fit

Use the smallest suitable hole. This minimises immediate leftover space, but can create small holes; it does not minimise total fragmentation in general.

Worst Fit

Use the largest suitable hole. It leaves a larger remainder, but may consume a hole needed for a later large request.

Next Fit

Like First Fit, but resume searching from the previous position. It does not guarantee uniform placement.
